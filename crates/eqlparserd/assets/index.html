Overlay

Add this as an OBS Browser Source, or open it in the desktop app:

http://127.0.0.1:8777/overlay

Set the source to about 360×420, tick Shutdown source when not visible off, and leave the background transparent — the page paints no background of its own.

Overlay options

ParameterEffect
?panels=meter,buffsWhich panels to show
?rows=6Max damage meter rows
?scale=1.25Zoom, for 4K captures
?width=340Overlay width in pixels
?self=1Show only your own row
?enemies=0Hide enemy rows
?idle=1Keep the last fight on screen between pulls

API

  • /api/snapshot — current state
  • /api/encounters — history (?search=, ?zone=, ?limit=, ?offset=, ?min_duration=)
  • /api/loot — aggregated loot
  • /api/classes — detected classes
  • /ws — live snapshot stream
