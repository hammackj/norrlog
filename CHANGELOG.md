# Changelog

## 0.1.0 (2026-11-16)

The first public release. Norrlog was developed privately as eqlparser before
this; this is the first version built for others to install.

- **Two games.** EverQuest and EverQuest Legends, each with its own install,
  logs and history, switched in Settings.
- **Fights.** Every fight found automatically, with damage, DPS, healing, damage
  taken, crits and a per-ability breakdown for you, your group, your pets and
  the creatures you fought. Search, filter and export (`.md`, `.csv`).
- **Live meters** for the current fight, the session and the zone, and an
  **OBS overlay** served by the daemon, with floating combat text, buff timers,
  alert banners and countdowns.
- **Buff timers** from the game's own spell file.
- **Loot and drops**, taken or left on the corpse, with the kills behind every
  count.
- **Experience** per class and zone, alternate advancement, a calibration for
  the bar's exact percentage, and kills left to the next level.
- **Tradeskills, foraging, a bestiary, tells, log search**, and a **Quest
  Tracker** with Plane of Sky progress (EverQuest Legends).
- **Alerts** built from any log line: sound, speech, overlay banners and
  countdowns. GINA triggers import from `.gtp` or XML, and export as `.gtp`.
- **Updates.** Installed copies (AppImage, Windows installer, macOS app) offer a
  newer release on launch and install it only when you choose to, and only if
  it is signed with the release key.
- Linux AppImage; Windows installer and portable zip; macOS (Apple Silicon)
  disk image. Windows and macOS are experimental.
